# Atividade Prática – Modelos de Páginas (Rede Social)

## 📅 Entrega
- **Data:** 12/04/2026  
- **Horário:** 23:59  
- **Tipo:** Individual  

---

## 📌 Descrição Geral
Desenvolver **5 modelos de páginas** para um mesmo site (rede social).  
A atividade é contínua e dará sequência à Atividade 2, estando relacionada ao projeto final da disciplina.

---

## 📄 Páginas Obrigatórias
1. Portal do site  
2. Login de usuário  
3. Área de usuário  
4. Histórico  
5. Conexões  

---

## 🧩 Requisitos por Página

### 1. Portal
- Exibir postagens de amigos
- Campo de busca para postagens por:
  - Nome completo do usuário
  - Parte do nome

---

### 2. Login
- Formulário com:
  - Campo de login
  - Campo de senha
- Botões:
  - Submeter
  - Limpar formulário
- Opção de:
  - Recuperação de senha por e-mail

---

### 3. Área de Usuário
- Exibir:
  - Quantidade de amizades
  - Quantidade de visualizações das postagens

---

### 4. Histórico
- Listar postagens do usuário:
  - Ordenadas da mais recente para a mais antiga
- Opções para cada postagem:
  - Apagar
  - Atualizar
- Formulário para:
  - Criar nova postagem

---

### 5. Conexões
- Listar amigos do usuário
- Funcionalidades:
  - Buscar novos amigos
  - Solicitar conexão
  - Cancelar conexão

---

## 🎨 Requisitos de Layout e Conteúdo
- Utilizar **layout com CSS** (preferencialmente Flexbox ou similar)
- Conteúdo **fictício obrigatório**, incluindo no mínimo:
  - 10 postagens
  - 10 conexões
  - 10 itens no histórico

---

## 🧪 Critérios de Avaliação
- Entrega das **5 páginas completas**
- Uso correto de:
  - Figuras
  - Botões
  - Formulários
- HTML seguindo o padrão **W3C**
- CSS separado do HTML
- Imagens organizadas em pasta específica
- Presença de uma **identidade visual única**

---

## ⚠️ Observação Importante
- Inserir no **Portal do site**:
  - Nome do aluno
  - RA (Registro Acadêmico)
